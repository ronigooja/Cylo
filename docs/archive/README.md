# Historical research archive

This archive preserves the research available at source commit `f66e455` (2026-10-21). Only [the master plan](../master-plan.md) specifies current implementation requirements. Historical proposals, including PWA delivery, CAO changes and broader server platforms, do not override it.

The original Chinese prose is available through Git history. Markdown translations preserve historical decisions, dates, source versions, limitations and evidence classifications; quotations may retain their original language. Scripts, JSON and raw outputs are moved without content changes. The former README is replaced by the current repository entry point and remains available at the source commit.

Evidence levels used in the source material are distinct: requirement/design proposal; source inspection; fixture or mock test; reported user environment; and real external experiment. None establishes production acceptance unless its stated test actually exercises that boundary. The synthetic Codex handoff experiments do not establish AO integration, live tool execution, mobile audio, or production recovery.
