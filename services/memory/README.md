# Cylo memory worker

The worker maintains derived Mem0/Qdrant state under the [Go authority](../../docs/architecture.md#memory-retrieval-and-context). See [deployment operations](../../docs/operations/deployment.md#server-and-worker-settings), [data lifecycle](../../docs/operations/data-lifecycle.md), and [acceptance evidence](../../docs/acceptance/evidence.md) for their respective boundaries.

Dependency versions are locked in [pyproject.toml](pyproject.toml) and [uv.lock](uv.lock). [config.py](config.py) pins the multilingual embedding revision, dimension, and codec; [embedding.py](embedding.py) checks model artifacts. A codec change requires a new collection rebuilt from Go authority. [Compose](docker-compose.yml) uses disposable Qdrant tmpfs and persists Mem0 history, ownership metadata, and model cache in `memory-worker-state` at `/var/lib/cylo/memory`; include that volume in the applicable backup/deletion inventory.

The opt-in cross-language harness lives in [e2e_worker.py](tests/e2e_worker.py) and [Go integration tests](../../tests/integration/). Supply `CYLO_MEMORY_E2E=1`, `CYLO_MEMORY_E2E_LLM_BASE_URL`, `CYLO_MEMORY_E2E_LLM_MODEL`, and `CYLO_MEMORY_E2E_LLM_API_KEY` through deployment references to run `go test ./tests/integration -run '^TestMemoryWorkerGoPythonMem0QdrantEndToEnd$' -count=1` on a GitHub-hosted Linux runner. It uses synthetic sources, a temporary authority database, and disposable Qdrant; a Responses stub exercises composition only.

Each Responses API request reserves a call and an input estimate equal to the UTF-8 request bytes plus framing allowance, together with its requested output-token ceiling, in the Go authority before dispatch. The default per-job limits are four physical calls and 192,000 reserved units. Reservations count across retries; an uncertain or crashed call remains reserved. Provider usage is recorded when returned and stays explicitly unknown when absent. Later budget checks count the greater of a call's reservation or measured usage. The estimate is not provider usage or a tokenizer-specific guarantee; accounting does not set monetary cost. SDK retries are disabled so one reservation authorizes one physical request. `ollama` is rejected until its calls can use the same accounting path.

Cleanup removes Mem0 history only when the worker can prove claim ownership from the durable ownership map or surviving vector metadata. Pre-ledger history without such an owner remains untouched; the Mem0 history schema has no safe claim mapping for those rows.
